# 📊 Bank Customer Churn Analysis Dashboard

## Project Overview

Customer churn is one of the most important challenges faced by banks. Retaining existing customers is often more cost-effective than acquiring new ones. This project focuses on analyzing customer behavior and identifying factors that contribute to customer churn.

The dashboard was built using Power BI to provide interactive insights into customer demographics, account details, and behavioral patterns that influence customer attrition.

---

## 🎯 Objective

The primary objectives of this project are:

* Analyze customer churn patterns.
* Identify customer segments with high churn risk.
* Understand factors influencing customer attrition.
* Support data-driven customer retention strategies.
* Create an interactive dashboard for business stakeholders.

## 📊 Dashboard Features

### 1. Churn Rate by Country

Analyzes churn behavior across different countries to identify geographical trends.

### 2. Tenure vs Churn Rate

Shows how customer tenure impacts churn probability.

### 3. Product Number vs Churn Rate

Examines the relationship between the number of products owned and churn behavior.

### 4. Active Status vs Churn Rate

Compares churn rates between active and inactive customers.

### 5. Age Group vs Churn Rate

Analyzes churn across different age categories.

### 6. Interactive Filters

Users can filter data by:

* Gender
* Country
* Credit Score Group

---

## 🔍 Key Insights

### Geography Analysis

* Germany has the highest churn rate among all countries.
* France and Spain show comparatively lower churn rates.

### Customer Activity Analysis

* Inactive customers are significantly more likely to churn.
* Active customers demonstrate stronger retention.

### Age Analysis

* Senior customers exhibit the highest churn rate.
* Younger customers have the lowest churn rate.

### Product Analysis

* Customer churn varies significantly based on the number of products held.
* Product ownership patterns can be used to identify at-risk customers.

### Tenure Analysis

* Churn behavior changes across different tenure periods.
* Certain tenure ranges show increased churn risk.
